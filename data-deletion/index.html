Data Deletion

YZX Media · Changzhou Yuzhenxuan Trading Co., Ltd. · Changzhou, Jiangsu, China
Last updated: November 2026

1. What this covers

This page explains how to request deletion of data associated with the YZX Media publishing application used by Changzhou Yuzhenxuan Trading Co., Ltd. (the Company, we) to publish video content on the Company's own social channels.

2. What data the application holds

The application operates only on the Company's own accounts and channels. It does not collect, store or transmit data belonging to viewers, followers or any other third party.

Data held locally on Company-managed computers

  • OAuth access tokens issued by the platform provider, used to publish content. These expire and are discarded after each publishing operation.
  • OAuth refresh tokens, stored in a local configuration file on Company-managed computers. These are never committed to source control and are never transmitted over the network.
  • Draft metadata for videos prepared but not yet published, held in local working files until submitted.

Data published to the Company's own channels

Videos, thumbnails, titles, descriptions and tags submitted through the application are published to the Company's own channels, where they are visible to that platform's audience and are managed through the platform's own content tools.

3. How to request deletion

Send a request to the contact address below, stating which data you would like deleted. Include enough detail for us to locate it.

Requests are handled within 30 calendar days. We will confirm by email once the request has been processed.

What we can delete

  • Local OAuth credentials and any locally held draft metadata for the Company's publishing tools.
  • Content published by the application on the Company's own channels, when you specify the post, video or page. Deletion of published content also removes the platform's record of it.

What we cannot delete

We cannot delete content on a platform account that we do not control, and we cannot retrieve third-party copies of content that has already been republished or downloaded elsewhere.

4. Revoking access

If you have authorized the application and want to withdraw that authorization, you can remove it at any time through the platform provider's own permissions page — for example, at myaccount.google.com/permissions for Google, or the equivalent settings page of the relevant platform. Revoking access stops the application from obtaining new access tokens, and the refresh tokens held locally stop working.
